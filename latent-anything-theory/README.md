# Latent-Anything Theory

It is a sub-project to research all theory related to Latent-Anything Project.

It follows the [Theory Index (THEORY.md)](https://github.com/triet4p/latent-anything/blob/main/docs/THEORY.md) — the master roadmap. (THEORY.md lives at the repository root, outside this docs site, so it is linked on GitHub rather than as an internal page.)

## Mục lục

- **[1. Biểu diễn không gian](01-space-representation/research/01-metric-space-vector-space.md)** — metric space, Mahalanobis, manifold hypothesis, curse of dimensionality, geodesic, pullback metric, FlatVI.
- **[2. Representation Learning](02-representation-learning/research/01-information-bottleneck.md)** — information bottleneck, autoencoder, VAE/β-VAE, VQ-VAE, VQGAN.
- **[3. Hình học & Cấu trúc](03-geometry-structure/research/01-linear-structure.md)** — linear structure, disentanglement, isotropy/anisotropy, Riemannian geometry, slerp, normalizing flows.
- **[3B. 3D Representation](03b-3d-representation/research/01-neural-implicit-representation.md)** — neural implicit representation, NeRF, volume rendering, positional encoding, Instant-NGP.
