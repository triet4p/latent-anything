## Probe And TCAV Gap Decision

No shipped probe, `LinearProbe`, or TCAV implementation exists in `src/`, `tests/`, or `scripts/`. Existing matches are theory and architecture references only.

Decision: do not add a rushed probe increment in Sprint 26. This is a release-preparation sprint, and the existing beta surface is already coherent without implying the full Layer A theory scope. Probing/TCAV should be explicitly scoped as future work in the README and release notes.

## Visualization Readiness

Current visualization is sufficient for a beta if positioned honestly:

- Static matplotlib plots and text summaries are enough to demonstrate beta capabilities.
- The tracked artifacts are discoverable once a release demo index links them.
- Interactive Plotly dashboards, notebook widgets, and polished app-style inspection surfaces remain future work.

The release should not claim interactive visualization. It can claim script-level visualization artifacts and reproducible demos.

## Conclusion

The current demos show enough Layer A and Layer B behavior to justify the beta title, especially through the showcase, manipulation pipeline, Gaussian renderer, and runtime summaries. The release notes must clearly state that probing/TCAV and interactive visualization are future work.
