# Sprint 27 Plan

## Sprint Goal

Define a measurable `1.0.0` evidence contract and turn the theory index into a live capability ledger that cannot be satisfied by documentation-only coverage.

## Atomic Tasks

Status legend: [ ] pending / [~] in progress / [x] done

- [ ] Inventory every item in `docs/THEORY.md` and assign a stable capability identifier.
- [ ] Classify each item as implementation-applicable, benchmark-only, or contextual background, with a written rationale for exclusions.
- [ ] Create the D0-D3 evidence ledger with links to source, tests, demos, benchmarks, and model artifacts.
- [ ] Define the exact 95% core / 90% overall denominator and automate percentage calculation in a read-only validation script.
- [ ] Set quantitative quality gates for core tests, integration tests, documentation, explanation validity, and compatibility.
- [ ] Add a CI check that rejects stale or broken evidence links without requiring optional model downloads.
- [ ] Reconcile the ledger contract with IDEA, ARCHITECTURE, INCREMENTAL, and the existing beta theory matrix.
- [ ] Record the sprint artifact, ADR outcome, changelog impact, and full gate results.

## Notes / Blockers

This sprint defines measurement; it does not claim new theory coverage. D0 research notes and notebooks remain valuable but do not count toward the stable implementation percentage.
