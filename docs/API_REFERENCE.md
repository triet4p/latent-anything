# API reference and frozen surface

This page is a human index to the mechanically generated API contract. It does
not duplicate every generated signature or default. The checked-in snapshot is
the source of truth:

```text
artifacts/api_freeze_snapshot_0.1.0b1.json
```

Regenerate only after a reviewed public-surface change, then run:

```text
uv run python scripts/api_freeze_snapshot.py --check
uv run pytest tests/test_api_freeze_snapshot.py tests/test_api_compatibility.py -q
```

The snapshot normalizes sorted JSON keys and contractually public declaration
order; it excludes object addresses and unstable representations. Its current
digest is `48d64721b73a9d0c9e73da4a41940008c70dfa7841e500bc11bc8dcd22ddf7f6`.

## Configurations and results

Snapshot section G mechanically inventories **28 config schemas**, including
required fields, defaults, and default factories. Build through
`ObjectSpec`, `build_from_config`, or `build_from_dict` and use canonical
registry kinds (`adapter`, `analysis`, `intervention`, `runtime`). The two
registry-kind aliases and `MPPIConfig` input aliases are documented in
[`MIGRATION.md`](MIGRATION.md).

The human ledger expands snapshot section B into **18 alias rows**; the two
schema/path data migrations are separate compatibility mechanisms and are not
included in that alias count.

Section H inventories **81 public dataclass/result schemas**. Result aliases
are read-only compatibility properties: planner results expose canonical
`actions`, rollout results expose canonical `trajectory`, and transition
metrics expose descriptive negative-log-likelihood/error names. Exact field
types and defaults belong to the snapshot, not this prose page.

## Registry, plugins, and optional profiles

- Built-in registry: **32** rows across adapter, analysis, intervention, and
  runtime kinds. Factories, modules, and names are section D.
- External plugin groups: **5**, API version **1**:
  `latent_anything.adapter`, `.analysis`, `.intervention`, `.transition`, and
  `.planner`. Listing is metadata-only; loading is explicit and untrusted.
- Optional profiles: **12**, in pyproject order: `docs`, `diffusers`,
  `transformers`, `diffusers-full`, `3d`, `lerobot`, `lerobot-diffusion`,
  `lerobot-smolvla`, `viz`, `tracking-mlflow`, `tracking-wandb`, `tracking`.

The base import must not import optional provider modules. Missing optional
dependencies use the actionable `require_optional` boundary, for example:
`Optional backend 'lerobot' is unavailable. Install with: uv sync --extra
lerobot`. Provider-specific nested dependency errors remain intact.

## CLI contract

The five commands are `capture-points`, `inspect-policy`, `inspect-dataset`,
`replay-run`, and `compare-runs`. The aliases are `list-capture-points` and
`replay-run-config`. Section I is generated by introspecting argparse actions,
aliases, choices, required flags, defaults, and nargs; successful `main()`
returns 0, malformed parser input returns 2, and runtime failures are typed
domain exceptions with a non-zero process exit.

## Explicitly non-API inventory

SAM, OpenCLIP, timm, Torchvision model adapters, Open3D, trimesh, and an
unnamed 3DGS checkpoint are not stable public APIs. They remain backlog or
M14 blocker rows. Likewise, a compact fixture or a historical artifact does
not establish a real checkpoint, hosted provider, CUDA, or model-quality
claim. Diffusers, Transformers, gsplat, LeRobot, MLflow, W&B, Plotly/Kaleido,
and related provider objects are optional boundaries, not base-package API
requirements.
